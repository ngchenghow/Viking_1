# Viking_1

**Viking_1** is a 3D game demo built in **C++**, showcasing fundamental 3D rendering, camera movement, and game loop management.  
It serves as a base project for experimenting with 3D graphics, input control, and performance optimization.

---

## Features

- Custom **C++ 3D engine** for rendering models and scenes  
- Basic **camera control** (rotate, pan, zoom)  
- Real-time **lighting and shading**  
- Keyboard and mouse input handling  
- Frame-based **update loop**  
- Modular structure for easy extension and learning

---

## Technology Stack

- **Language:** C++17  
- **Graphics:** DirectX / OpenGL (depending on configuration)  
- **IDE:** Visual Studio 2022  
- **Platform:** Windows x64
